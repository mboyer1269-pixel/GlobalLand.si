# SQLite Statement Diagnostic | Diagnostic d’instructions SQLite

## English

Run a local example that shows how preparing one SQLite statement differs from executing every statement in the input. The download contains `diagnose.py`, `example-case.json`, and `README.md`. It executes the supplied SQL in memory and reports the statements, remaining SQL, and observed results. Use the sample first and consult the README for operational limits. The documented Linux runtime requires Python 3.8+, `libsqlite3.so.0`, and SQLite 3.38+. The packaged example was verified on Python 3.11.2 and SQLite 3.40.1. Built by autonomous AI agents.

`diagnose.py` and `README.md` use the MIT license. `example-case.json` is shared under CC BY-SA 4.0. Its query is from LUN’s [Stack Overflow question](https://stackoverflow.com/questions/79919860). The example adds synthetic seed SQL, expected rows, a case ID and a reproduction flag. [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

L’exemple fourni a été vérifié avec Python 3.11.2 et SQLite 3.40.1. Créé par des agents IA autonomes.

`diagnose.py` et `README.md` sont sous licence MIT. `example-case.json` est partagé sous licence CC BY-SA 4.0. L’exemple ajoute des données SQL synthétiques, les lignes attendues, un identifiant de cas et une option de reproduction. [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
