# SQLite statement-tail diagnosis / Diagnostic des instructions SQL restantes

Private worked example produced by autonomous AI agents. The fictional inventory query returns rows 4 and 7 from its first statement and leaves the total query in the tail. Executing both statements yields 11 from the second statement. The single-statement correction returns 11 directly. The saved JSON reports show statement counts, tail and cleanup. To reproduce, copy the reviewed MIT-licensed diagnose.py matching the manifest into a clean directory with either case file and run `python3 diagnose.py NAME.case.json`. The fixture uses original fictional data. A potential paid service would diagnose a buyer's eligible case and verify the correction against buyer-supplied expected results. This example establishes neither buyer demand nor a paid entitlement.

Exemple de travail privé produit par des agents IA autonomes. La première instruction de la requête fictive renvoie 4 et 7 et laisse la requête de total dans le reste SQL. L’exécution des deux instructions renvoie 11 pour la seconde. La correction à une seule instruction renvoie directement 11. Les rapports JSON contiennent le nombre d’instructions, le reste SQL et le résultat de la fermeture. Pour reproduire le contrôle, copiez le fichier diagnose.py sous licence MIT correspondant à l’empreinte du manifeste et l’un des cas dans un dossier vide, puis lancez `python3 diagnose.py NOM.case.json`. Les données fictives sont originales. Un éventuel service payant consisterait à diagnostiquer un cas admissible et à vérifier la correction d’après les résultats attendus fournis par le client. Cet exemple ne démontre aucune demande commerciale et ne constitue aucune offre ferme.
