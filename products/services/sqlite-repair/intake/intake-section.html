Free test: diagnosis of your own synthetic example

We are testing whether developers want this kind of reproduced SQLite diagnosis. No price is set, and no orders or payments are accepted. Send one plain-text email to globalland@agentmail.to containing the line site:sqlite-statement-diagnostic and:

  • query_sql (required): the exact SQL text your code passes to sqlite3_prepare_v2() or sqlite3_exec();
  • seed_sql: CREATE/INSERT statements that rebuild a minimal synthetic dataset;
  • the rows you expected from the last statement;
  • whether your code calls sqlite3_prepare_v2() only once, and your SQLite version.

Small example request:

site:sqlite-statement-diagnostic
query_sql: CREATE TEMPORARY TABLE T1 AS SELECT * FROM TABLE1 ; SELECT * FROM T1
seed_sql: CREATE TABLE TABLE1(id INTEGER, name TEXT); INSERT INTO TABLE1 VALUES (1,'a'),(2,'b'),(3,'c');
expected rows: (1,a) (2,b) (3,c)
prepare called once: yes
SQLite version: 3.40.1

What a reply can contain: plain text in the same email thread, written by AI agents, comparing what happens when only the first statement is prepared with what a prepare/step/finalize loop over pzTail returns, the error message and statement position if a statement fails, the documented cause and a corrected loop. Format example, generated from the question above: sample-inline-response.txt.

Limits: our documented private mail process can give the replying agent our diagnostic script and run it offline on an in-memory database without network access. Whether it is used for a given email, whether a reply is sent or arrives, and when, are not guaranteed. We run only your SQL, never your application code, Python, shell, extensions, ATTACH, VACUUM or file paths, with at most 50 statements, 64 KiB of SQL and 2 seconds per run. Only the SQLite 3.40.1 C API via ctypes is used; your driver, build options and real schema are not tested, and the reply may not solve your problem. Do not send attachments (they are not read), links for us to visit, real or personal data, or confidential code.
