[[Category:Organised editing activities|Berlin Radinfrastruktur]]
== Overview ==
This page documents the planned organized editing activity by [[FixMyCity GmbH]] to map and update bicycle and road infrastructure within Berlin’s ''Ergänzungsnetz'' (Supplementary Cycle Network) in OpenStreetMap (OSM). The resulting data is intended to support bicycle network planning by the City of Berlin.

This project is the successor of the project [[Organised_Editing/Activities/Berlin_Radinfrastruktur_(Vorrangnetz)|Berlin Radinfrastruktur (Vorrangnetz)]].

* '''Start date''': September 2026
* '''Expected End date''': September 2027

We will update this project page promptly when changes occur.

== Goals ==

The project aims to collect comprehensive and precise data on Berlin's Cycle Network of approx. 2100 km (both sides). This includes bicycle ways as well as roads where no bicycle ways are present (mixed traffic, "Mischverkehr").

The data will then be further processed to prepare it in a way that can be easily used for planning tasks by the City of Berlin.

The long-term plan is to monitor and update the data to allow for quick updates to the dataset used for planning purposes.

== Scope of Mapping ==

In general, the mapping covers all cycle infrastructure along the „Radergänzungsnetz“, the „Hauptverkehrsstraßen“, part of the „Radschnellverbindungen“ and may also contain changes to the „Radvorrangnetz“, including the types of cycleways (protected lanes, painted lanes, shared traffic, etc.), based on the processing done in [[FixMyCity_GmbH#TILDA_Radverkehr|TILDA]], which is publicly available as part of https://radinfra.de/. We will also update general road data where cyclists have to use the road in mixed traffic.

== Contact ==

First, please contact the individual mapper or use the changeset discussion. If no conciliation is successful, please contact one of the [[#Project_coordinators|coordinators at FixMyCity]].

== Community Consultation ==

We will reach out to the local mapping communities for comments and concerns.

== Hashtag ==
The editors are summoned to use the hashtag <code>#fmc-nebennetz</code> on all changesets.

== Tagging ==

We will follow the established mapping practices for roads and bike lanes, namely:
* [[DE:Bicycle/Radverkehrsanlagen kartieren|General recommendations on bike infrastructure mapping]]
* [[Verkehrswende-Meetup/Radwege|Additional recommendations on mapping bicycle infrastructure]]
* [https://radinfra.de/dokumentation/fuehrungsform/ Tagging recommendations for TILDA to categorize bicycle infrastructure], especially [[Proposal:Key:is sidepath|is_sidepath]] and [http://Proposal:Separation separation:*] where needed.
