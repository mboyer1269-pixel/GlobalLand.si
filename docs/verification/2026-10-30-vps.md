## Limites et décisions

- `docker info` : impossible ici, accès au socket du démon refusé. Aucun conteneur, VPS ou GitHub Deploy Key réel testé. Aucun déploiement.
- Node 22 et CI GitHub : à confirmer par les checks de PR ; le runtime local est Node 24.
- AGENT_CODE reste désactivé même avec une signature valide ; Ed25519 est une primitive testée, pas un circuit payant activé. Zéro appel API payant, zéro accès aux clés de production.
- Registre public initial limité à AUDIT. Les anciens scripts produits/shell ne sont plus exécutables par la file.
- Une exécution incertaine n'est pas rejouée automatiquement. Un audit quotidien interrompu demande une réconciliation opérateur ; une tâche interrompue publie INTERRUPTED.
- Conserver les journaux privés pour l'anti-rejeu ; sauvegarde et rapprochement manuel requis en cas de divergence Git ou restauration.
- Le scan de secrets reste heuristique ; le ledger ne prouve pas la réalité bancaire. Voir SECURITY.md et INSTALL.md.

Aucune garantie de déploiement réussi ni de confinement absolu n'est revendiquée. Le test réel de bout en bout reste un prérequis avant cron.
