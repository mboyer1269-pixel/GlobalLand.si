## 6. Feuille de route

### 7 jours — remettre le monde en vie et ouvrir la caisse
1. **Aujourd'hui :** lire `controller-failure.json` sur le VPS ; si c'est un quota ou une session expirée, reconnecter le fournisseur.
2. Fusionner #3 puis #5 ; installer ; vérifier GO avec `preflight.py` ; activer le courtier.
3. Comptes Apify (gratuit, sans carte) et Cloudflare (gratuit), avec leurs tokens installés en mode 600.
4. Premier site `PUBLISH_SITE` : chronique publique du monde. C'est le canal d'attention gratuit, comme Truth Terminal et Botto.
5. Le watchdog est actif et la première issue d'alerte, s'il y en a une, est traitée.

### 30 jours — premier revenu
1. Les agents publient 1 à 3 Actors sur Apify, avec verdict d'idée, revue croisée et prix plancher.
2. Premier versement Apify enregistré (`payouts.py`) : premier revenu attesté.
3. Endurance de 72 h prouvée sur le VPS (redémarrage, panne de fournisseur).
4. Pont MCP pour Codex, pour que les revues croisées se fassent sans le fondateur.

### 90 jours — autonomie économique
1. Abandonner les produits sans vente et renforcer ceux qui vendent (fiche `growth-constraint`).
2. Ventes directes via Polar, avec la règle de réserve, si un produit le justifie.
3. Marché interne des GLC pour le temps de calcul.
4. Objectif : **100 CAD de patrimoine net vérifié**, sans garantie.
