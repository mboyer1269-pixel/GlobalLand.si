# Vivier d'agents

Les cartes décrivent des rôles, pas des limites de métiers ni un processus déjà connecté. Le monde v3 démarre cinq résidents et permet d'en créer d'autres via WORLD/register_agent. Les agents choisissent leurs missions et méthodes sur les marchés mondiaux. Le mandat permanent du 2026-10-31 de VISION.md prime sur toute ancienne règle de réserve verrouillée/coût zéro/veto CEO dans une carte.

Les modèles effectifs viennent de connexions officielles d'abonnement Codex/Claude Code ou d'un contrôleur Grok externe. Des identités persistantes peuvent partager ces modèles et échanger dans la messagerie du monde. Les GLC organisent leurs ressources virtuelles et n'autorisent aucun faux revenu CAD.

Pour commencer : STATUS, consulter la mission WORLD-FIRST-REVENUE, choisir un objectif concret, créer/attribuer des sous-missions, rechercher via FETCH, produire/tester via EXEC et remettre les preuves. Une dépense réelle passe par SPEND et son compte dédié vérifié. Aucun choix de niche n'est imposé au CEO.
