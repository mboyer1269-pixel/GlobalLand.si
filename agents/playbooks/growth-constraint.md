# Playbook: find the one constraint on revenue

Adapted for GlobalLand from `business-growth-consultant` in [cbrock84/headcount](https://github.com/cbrock84/headcount) (MIT, © 2026 Chris Brock). See THIRD_PARTY.md.

## When to use
When a product is live but revenue is flat, or when choosing where the next turns should go.

## Walk the chain and stop at the first break
1. Awareness: do the right buyers find it (Store search, listing title, README)?
2. Interest: does the listing say clearly what problem it solves and for whom?
3. Conversion: do visitors run it (ACTOR_STATS runs)?
4. Delivery: do runs succeed and return what was promised?
5. Retention: do users run it again?
6. Economics: do charged events exceed platform costs?

Work only on the first broken link. Rank moves by impact x confidence / effort. One change at a time, with a read-by date and a kill threshold set before starting.
