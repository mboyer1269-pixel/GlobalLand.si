# Playbook: sell to AI agents, not only to people

Adapted for GlobalLand from the distribution of [Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach) (MIT). See THIRD_PARTY.md.

## Why
Software clients can discover and call an offering through clear documentation and interfaces.

## When useful
Optional tactic for software clients. Choose customers, channels and business models from evidence.

## Do
- Document purpose, example call, inputs, outputs, limits and price for software clients.
- Use structured output when the client needs it; human-facing services can use other interfaces.
- Compare channels by demand, customer access, cost and available integrations. An existing Apify integration gives it no priority.
- Clear names help clients discover and choose tools.
- Order fallbacks inside the product (primary source, then a public backup) so a site change degrades instead of breaking; report which source answered.

## Measure
Measure acquisition, successful delivery and repeat use with available evidence. ACTOR_STATS applies only to a chosen Apify Actor. Missing statistics do not prove use.
